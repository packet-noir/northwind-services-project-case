# Identity Naming Convention
This document outlines the standard naming convention for groups and user principals.
## Groups
Naming pattern follows a \[GROUP TYPE]-\[DIMENSION]-\[VALUE] scheme.

This helps differentiate between group types (Security/Distribution/M365), and allows for flexibility when grouping by location, role or department.
### Examples
- SEC-DEPT-RADIOLOGY
- SEC-ROLE-RN
- SEC-LOC-TAMPA
## User Principal Names
UPN value will be named after the user's first and last name, with a period separating the two.
### Example
- first.lastname@domain.com
Users with similar names may have a number appended to their UPN.
