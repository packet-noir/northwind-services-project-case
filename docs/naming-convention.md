# Identity Naming Convention
This document outlines the standard naming convention for groups and user principals.
## Groups
Naming pattern follows a \[GROUP TYPE]-\[DIMENSION]-\[VALUE]
This helps differentiate between group types, and allows for flexibility when grouping by location, role or department. 
"SEC-DIMENSION-VALUE"
### Examples
- "SEC-DEPT-RADIOLOGY"
- "SEC-ROLE-RN"
## User Principal Names
first.lastname@domain.com
